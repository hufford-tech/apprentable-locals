# Map boundary source

`us_atlas_states_10m.json` is `states-10m.json` from `us-atlas` 3.0.1:
https://github.com/topojson/us-atlas

The US Atlas data is derived from US Census Bureau cartographic boundaries.
The `us-atlas` package is distributed under the ISC license. The finder
projects and simplifies the 50 states and DC at build time; it makes no map
data request at runtime. The full license text is in `LICENSE-us-atlas.txt`
and is embedded in the generated finder HTML.
