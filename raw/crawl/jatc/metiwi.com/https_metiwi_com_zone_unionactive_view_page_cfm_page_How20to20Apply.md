| ## Step-by-step support. No guesswork.<br>Applying to METI shouldn’t feel like a mystery — and we’re here to make it simple. Whether you’re just finishing high school or switching careers, our application process is built to guide you every step of the way.<br>Here’s how it works: | |
| |     |     |
| --- | --- |
| |     |     |
| --- | --- |
| ![](https://metiwi.com/images/Apprentice%20Shots/two%20apprentices.jpg) | ## Step 1: Choose Your Path<br>Before you apply, decide which training program is right for you:<br>- **Inside Construction**<br>  <br>  <br>   → Apply for the Apprenticeship program (classroom + field learning, ~5 years) → Or apply for the CW/CE Training Program (hands-on, field-based, self-paced)<br>- **Residential Construction**<br>  <br>  <br>   → Apply for the Residential Construction Worker (RCW) program<br>- **Sound & Communication**<br>  <br>  <br>   → Apply for the Sound & Communication Technician Training Program<br>Need help deciding? | | |
| |     |     |
| --- | --- |
| |     |     |
| --- | --- |
| ![](https://metiwi.com/images/Female%20apprentice.jpg) | ## Step 2: Complete Your Application<br>**Each pathway has a different application process, handled by a different office.**<br>Following the correct steps will help avoid delays. |

|     |     |
| --- | --- |
| ## Applying for the Inside Construction Apprenticeship<br>**Administered by the Milwaukee Electrical Training Institute (METI)**<br>If you are applying for the **Inside Construction Apprenticeship**, METI handles all applications and questions.<br>### **How the Apprenticeship Application Works**<br>1. **Review the Apprenticeship Application Steps**<br>   <br>   <br>    This guide walks you through required qualifications, testing, and timelines.<br>   <br>2. **Complete the required application and testing process**<br>   <br>   <br>    Applicants move through aptitude testing as part of a competitive selection process.<br>   <br>3. **Placement with a contractor**<br>   <br>   <br>    Accepted applicants are placed with a signatory contractor and begin paid, on-the-job training while attending required classes.<br>   <br>### **Questions about the Apprenticeship?**<br>**Contact the Milwaukee Electrical Training Institute (METI)**<br>**414-543-9060**<br>**[info@metiwi.com](mailto:info@metiwi.com?subject=Questions%20about%20the%20Apprenticeship)** | ## Applying for Other Training Programs<br>**Administered by the International Brotherhood of Electrical Workers Local 494**<br>If you are applying for any of the following training programs, the I **BEW Local 494 office** handles all applications and administration:<br>- **Inside Construction – Construction Wireman / Construction Electrician (CW/CE) Training Program**<br>  <br>- **Residential Construction Training Program (RCW)**<br>  <br>- **Sound & Communication Technician Training Program (CTECH)**<br>  <br>### **How These Training Program Applications Work**<br>1. **Complete the online training program application**<br>   <br>   <br>    All three programs use the same application form. You will select which training program you are applying for.<br>   <br>2. **Hear from an IBEW Local 494 organizer**<br>   <br>   <br>    After your application is received, an organizer will contact you by email to explain next steps.<br>   <br>3. **Connect with union contractors**<br>   <br>   <br>    Applicants reach out to signatory contractors to seek employment under their chosen training program.<br>   <br>4. **Begin onboarding once hired**<br>   <br>   <br>    When a contractor agrees to hire you, they notify IBEW Local 494 and the onboarding process begins.<br>   <br>### **Questions about CW/CE, Residential, or Sound & Communication Training Programs?**<br>**International Brotherhood of Electrical Workers (IBEW) Local 494**<br>414-327-5202<br>**[training@ibew494.com](mailto:training@ibew494.com)** | | |
