# 2023 CEU Dates for Type "E" Licenses Posted

Dates for the 2023 CEU "E" Type License classes are posted you can download the registration form.

CONTINUING EDUCATION FOR ELECTRICIANS

“2023 LICENSE RENEWAL YEAR”

LICENSE TYPES: E-1, E-2, E-4, E-5, E-9

There have been some new requirements for this class that we must following in order to be a provider.

       ·**Everyone must have their own copy of the 2020 NEC (available for purchase)**

       ·**Electronic copies of the 2020 NEC are permitted on a laptop or tablet - NO PHONES**

       ·**In Person classes limited to 50 people**

       ·**All classes must be recorded (In person & online)**

       ·**Online classes permitted**

       ·**Class must be completed by June 30, 2023**
