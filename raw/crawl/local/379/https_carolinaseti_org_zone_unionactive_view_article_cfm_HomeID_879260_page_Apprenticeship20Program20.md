| 1\. Access the application. [CLICK HERE](http://carolinaseti.unionactive.com/docs/cejatc_apprentice_application.pdf)<br>2\. Fill out the application using your computer or phone.<br>3\. Save the PDF on your computer or phone.<br>4\. Send the application to denise@carolinaseti.com.<br>5\. You will sign the application when you come in for your interview.<br>**How to save the PDF application to your device.**<br>  Internet Explorer Users<br>1\. Right-click the link to the PDF file, and then click “Save Target As” from the sub-menu.<br>2\. The File Download dialog box opens, and a progress bar allows you to monitor the download process.<br>3\. After the file is downloaded, the Save As dialog box opens.<br>4\. Specify the location on your computer where you want to save the file, and click the “Save” button.<br>5\. After the file is saved, click the Close button in the File Download dialog box.<br>6\. Open the file stored on your computer and the file will open, in the Adobe Acrobat Reader, automatically.<br>![](https://carolinaseti.org/images/InternetExplorerSave.gif)<br>  Firefox Users<br>1\. Right-click the link to the PDF file, and then click “Save Link As” from the sub-menu.<br>2\. The “Enter name of the flies to save to…” dialog box opens.<br>3\. Specify the location on your computer where you want to save the file, and click the “Save” button.<br>4\. After the file is saved, open the file stored on your computer and the file will open, in the Adobe Acrobat Reader, automatically.<br>![](https://carolinaseti.org/images/FireFoxSave.gif)<br>  Chrome Users<br>1\. Right-click the link to the PDF file, and then click “Save Link As” from the sub-menu.<br>2\. The “Save As” dialog box opens.<br>3\. Specify the location on your computer where you want to save the file, and click the “Save” button.<br>4\. After the file is saved, open the file stored on your computer and the file will open, in the Adobe Acrobat Reader, automatically.<br>![](https://carolinaseti.org/images/ChromeSave.gif)<br>  Download on IPhone<br>1\. Open the PDF file with the Safari browser.<br>2\. Wait for the PDF to load fully in Safari web browser<br>3\. Tap on the PDF file<br>4\. Open In pops up at the upper section.<br>5\. Select iBooks. |
