# Letter of Introduction

When going to sign another IBEW Locals' Book 2, you will typically need a "Letter of Introduction" and a Current Dues slip.

Each Local has their own list of criteria they want included in the Letter and each Local has a different way to submit your Letter. Some prefer the Letter to be emailed and some prefer it to be faxed.

PLEASE Contact that Local first, to find this information and include it on this form.

To request a Letter of Introduction, please Submit a Request form below and allow 1-2 Business Days to process.
