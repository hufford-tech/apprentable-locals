# Jurisdiction Map

### The IBEW Local 743 holds jurisdiction in southeastern Pennsylvania.

### The counties included are Berks, Schuylkill, Lancaster, Chester and Montogomery.

### Use this interactive map to see if your location falls within the IBEW 743 jurisdiction.

### This Jurisdiction Map is for use to estimate if a Job is located in IBEW Local Union 743's Jurisdiction.
