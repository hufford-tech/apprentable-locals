**PLEASE NOTE – THERE IS A NEW LABOR POWER APP! THE OLD “LABORPOWER MOBILE” APP WILL NO LONGER WORK. IF YOU HAVE THE OLD ONE DOWNLOADED YOU CAN START TO LOG IN AND IT WILL GIVE YOU A LINK TO THE NEW APP. IF YOU DON’T HAVE THE OLD APP OR ARE UNABLE TO FIND THE LINK SEARCH YOUR APP STORE FOR “LABOR POWER” – YOU WILL FIND A BLACK AND WHITE GEAR FOR THE NEW APP SYMBOL.**

LOG IN INSTRUCTIONS

DOWNLOADING LABORPOWER MOBILE

APPLE –

- GO TO THE APP STORE
- SEARCH “LABORPOWER” – THE SYMBOL FOR THE APP IS A BLACK AND WHITE GEAR
- INSTALL – ONCE INSTALLED, OPEN THE APP AND CLICK “GET STARTED”
- SELECT UNION “IBEW”
- SELECT LOCAL “IBEW LOCAL 68”
- ENTER YOUR USER NAME AND PASSWORD
- YOU WILL BE TAKEN TO THE HOME SCREEN – YOUR CURRENT CONTACT INFO
- REVIEW YOUR CURRENT CONTACT INFO TO INSURE IT IS UPDATED – SAVE ANY NEW INFORMATION IF ANYTHING HAS CHANGED
- IF ALL INFORMATION IS UPDATED USE THE MENU IN THE TOP LEFT CORNER (3 LINES) TO ACCESS THINGS SUCH AS JOB HISTORY, PAY DUES, REGISTRATION INFO, OR AVAILABLE JOBS
- WHEN IN THE “JOBS AVAILABLE” SCREEN YOU CAN VIEW ANY CURRENT AVAILABLE JOBS IF YOU ARE REGISTERED TO THE SAME BOOK AS THE JOB OPENING
- WHEN BIDDING IS OPEN (BETWEEN 5:30 PM TO 8:00 AM) YOU CAN BID ON ANY JOB OPENING THAT IS ON THE SAME BOOK YOU ARE CURRENTLY REGISTERED TO

ANDROID –

- GO TO THE PLAY STORE
- SEARCH “LABORPOWER” – THE SYMBOL FOR THE APP IS A BLACK AND WHITE GEAR
- INSTALL – ONCE INSTALLED, OPEN THE APP AND CLICK “GET STARTED”
- SELECT UNION “IBEW”
- SELECT LOCAL “IBEW LOCAL 68”
- ENTER YOUR USER NAME AND PASSWORD
- YOU WILL BE TAKEN TO THE HOME SCREEN – YOUR CURRENT CONTACT INFO
- REVIEW YOUR CURRENT CONTACT INFO TO INSURE IT IS UPDATED – SAVE ANY NEW INFORMATION IF ANYTHING HAS CHANGED
- IF ALL INFORMATION IS UPDATED USE THE MENU IN THE TOP LEFT CORNER (3 LINES) TO ACCESS THINGS SUCH AS JOB HISTORY, PAY DUES, REGISTRATION INFO, OR AVAILABLE JOBS
- WHEN IN THE “JOBS AVAILABLE” SCREEN YOU CAN VIEW ANY CURRENT AVAILABLE JOBS IF YOU ARE REGISTERED TO THE SAME BOOK AS THE JOB OPENING
- WHEN BIDDING IS OPEN (BETWEEN 5:30 PM TO 8:00 AM) YOU CAN BID ON ANY JOB OPENING THAT IS ON THE SAME BOOK YOU ARE CURRENTLY REGISTERED TO

VIA WEB BROWSER

- GO TO “ibewlu68.com”
- IN THE TOP BANNER OF THE HOME PAGE CLICK THE “MEMBER LOGIN” BUTTON
- ENTER YOUR USER NAME AND PASSWORD
- REVIEW YOUR CURRENT CONTACT INFORMATION TO INSURE IT IS UPDATED – SAVE ANY NEW INFORMATION IF ANYTHING HAS CHANGED
- IF ALL INFORMATION IS UPDATED USE THE MENU OPTIONS ALONG THE TOP BANNER “MY ACCOUNT”, “ADMINISTRATION”, “JOBS”, AND “REGISTRATION”
- USE THE “JOBS” DROP DOWN MENU TO VIEW THE “JOBS AVAILABLE”
- YOU CAN THEN VIEW ANY AVAILABLE JOBS AND BID ON A JOB IF YOU ARE NOT WORKING AND HAVE AN ACTIVE REGISTRATION ON THE SAME BOOK AS THE JOB OPENING (BIDDING IS OPEN BETWEEN THE HOURS OF 5:30 PM – 8:00 AM)
