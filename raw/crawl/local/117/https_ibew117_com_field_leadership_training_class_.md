# Field Leadership Training Class

- [July 20, 2026](https://ibew117.com/2026/07/20/)

![](https://ibew117.com/wp-content/uploads/2022/01/cropped-site-icon.png)

There will be a Field Leadership Training Class on Wednesday August 12th and Thursday 13th. This course satisfies the requirement for eligibility for percentage based foreman rates. The course is a two night class that runs from 4 to 8 pm. Please contact the hall to check availability for the class, sitting is limited. You must attend both sessions to receive credit.
