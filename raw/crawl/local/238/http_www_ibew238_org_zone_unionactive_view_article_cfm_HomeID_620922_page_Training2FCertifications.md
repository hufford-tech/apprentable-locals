| CPR/FIRST AID TRAINING |

|     |
| --- |
| |     |
| --- |

| |     |
| --- |
| ![](http://www.ibew238.org/pics/CPR%20&%20First%20Aide%20pic%20(1).jpg) |
| |     |
| --- |
|  | |

In this standard CPR/AED/First Aid certification course you'll learn how to perform CPR correctly on infants, children, and adults as well as how to use an Automated External Defibrillator (AED). You'll also learn first aid to care for wounds, cuts & scrapes as well as, drug overdoses, electroshocks, strokes, heart attacks and more. |
